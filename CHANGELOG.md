Same adversary flagged that `git show :path | gofmt -l` reports `<standard input>` instead of the file path, so the hook writes each staged blob to a temp file whose basename matches the staged path before invoking `gofmt -l`, then prints a literal `Fix: (cd .../smaug-go && gofmt -w <files>)` command on failure; and that conflict-marker detection via grep on `git diff --cached` misdiagnoses deleted markers as additions, so the hook uses `git diff --check --cached` which distinguishes added lines from context and handles wholly-new files correctly. Usability adversary measured that `go test ./...` is 22.8s cold not the "~10s" initial estimate because `cmd/smaug/integration_test.go` boots a real server + telnet harness (22.4s of the total); splitting via `go list ./... | grep -v '/cmd/smaug$'` drops the hard gate to ~0.6s cached while `cmd/smaug` integration tests became a warn-only section runnable on demand via `SMAUG_RUN_INTEGRATION=1` (CI still covers them). Same adversary scanned existing code and enumerated legitimate no-test files (`internal/types/*.go`, `internal/net/{server,telnet,mssp,mccp,msdp}.go`, `internal/handler/{reset,find}.go`, `internal/testclient/{telnet,ansi}.go`, `internal/util/log.go`, `internal/combat/stance_index.go`) to demote the TDD sibling check to warn-only with exclusions for `package main` (read first 20 lines and grep `^package main\b`), `// Code generated` headers, rename status (`R`), and already-staged `_test.go` siblings. Hard gates wired: conflict markers, gofmt on staged blobs, `go vet ./...`, unit tests. Warnings: integration tests, missing test sibling, >150-added-line files, new TODO/FIXME/HACK/XXX, commented-out code heuristic. Escape hatches `SMAUG_SKIP_VET=1` / `SMAUG_SKIP_TESTS=1` added explicitly so `--no-verify` does not become reflexive — scoped bypasses preserve the cheap gates. Rebase detection (`$(git rev-parse --git-dir)/rebase-merge` or `rebase-apply` exists) skips all test gates during replay so `git rebase -i HEAD~20` stays under 2s total instead of 20 × 22s. Fast-path early-exit when staged diff contains no `.go` files — doc-only commits (CLAUDE.md, db/, src/) skip vet/test entirely. Output contract: `ERROR:` prefix for hard-gate failures always followed by a literal fix command, `[warn]` prefix for advisory findings; final line is `OK: pre-commit checks passed` or `BLOCKED: N check(s) failed`.
